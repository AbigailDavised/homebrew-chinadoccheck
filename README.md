# Homebrew Tap for chinadoccheck-cli (chinadoccheck.com)

Official Homebrew tap for **[chinadoccheck.com](https://chinadoccheck.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/chinadoccheck
brew install chinadoccheck-cli
```

## Quick Test

```bash
chinadoccheck-cli --help
```

# ChinaDocCheck — China National Health Commission Doctor License Verification Engine

Production command-line utility and Model Context Protocol (MCP) toolset for **[chinadoccheck.com](https://chinadoccheck.com)**. Validates Chinese practicing physician license numbers via the National Health Commission (NHC) database, medical hierarchy tiers (Chief vs Attending Physician), and foreign physician temporary practice permits.
